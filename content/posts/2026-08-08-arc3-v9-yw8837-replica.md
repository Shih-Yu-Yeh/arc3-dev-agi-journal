## TL;DR

Replicated yw8837's LB-1.17 config without the program synthesis prompt. LB 1.10, +0.35 over V6. Confirmed that AGI_8/AGI_9 patches alone provide most of V4's improvement.

## Context

V6's regression confirmed that context budget increases hurt. The question now was attribution: did V4's improvement come from the program synthesis prompt, or from the AGI_8/AGI_9 patches?

V9 was designed as a controlled comparison: take V4's config, remove the program synthesis prompt, keep AGI_8 and AGI_9. If LB stays near 1.06, the prompt was the contributor. If LB drops to V2 levels, the patches were the contributor. If LB rises above 1.06, the prompt was actually hurting.

## Technical Choice

Replicated `yw8837/arc3-yw8837-lb-1-17` config exactly: same model (Qwen3.6-27B-FP8), same context window (32768), same temperature (0.6), same AGI_8/AGI_9 patches. Removed the program synthesis prompt addendum from V4.

The yw8837 kernel was a public LB-1.17 result. By replicating it exactly, I could (a) verify that my pipeline reproduces others' published results, and (b) establish a clean baseline for the AGI_8/AGI_9 patches without confounding from the synthesis prompt.

## Outcome Analysis

LB 1.10, +0.35 over V6's 0.75 (and -0.31 below V4's 1.06 if compared apples-to-apples without the context regression).

The yw8837 replication landed at 1.10 vs the original's 1.17. The 0.07 gap is within normal hidden-rerun variance and confirms my pipeline reproduces others' published results.

Attribution: V9 (AGI_8+AGI_9, no synthesis prompt) = 1.10. V4 (AGI_8+AGI_9+synthesis prompt) = 1.06. The synthesis prompt contributed approximately -0.04 LB, i.e. it was net-negative. The entire V4 improvement came from the AGI_8/AGI_9 patches.

This was the first clean attribution experiment. The lesson stuck: never stack patches without a plan to attribute.
